# Privacy Policy Draft

## Scope

Table Ink Canvas is an on-device Android note-taking app focused on stylus input and table-based note structure.

## Data Collection

- The app is designed to operate locally on device.
- No cloud sync or collaboration service is included in v1.0 scope.
- No OCR or AI processing service is included in v1.0 scope.

## Stored Data

- Note title and document content.
- Table block structure and cell content.
- Ink stroke data.
- Local image references used by notes.

## Export and Portability

Users can export note content through:

- PDF
- HTML + assets
- Markdown + assets
- Native `.ticnote` archive

## Crash and Diagnostic Data

- Local diagnostics may be present for development and debugging.
- Production telemetry policy and crash reporting integrations are out of v1.0 scope unless explicitly added.
