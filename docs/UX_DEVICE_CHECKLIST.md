# Final device confirmation checklist

Automated checks cover code correctness, lint, and APK packaging. Final hardware confirmation should focus only on device ergonomics:

- S Pen pressure and eraser feel.
- Finger pan versus pen writing separation.
- IME behavior with the device keyboard configuration.
- Selection handle comfort at the device density.
- Large-note frame pacing and image memory pressure.

These are physical-device observations rather than unresolved implementation tasks.
