# NeoNote Visual Debt

Milestone 3 visual baseline is accepted for continued development.

Known visual debt:
1. Inline table still has minor form-like traces.
2. Toolbar icons need final polish.
3. Screenshot automation is incomplete.
4. Active cell style can be refined later.
5. Row/column controls need final polish.
6. Final color, spacing, and typography polish remains.

These are NOT blockers for:
- Normal/Debug split
- true infinite canvas
- lasso selection
- multi-select group movement
- image paste
- LaTeX rendering
- export

Do not reopen Milestone 3 unless:
- Normal Mode becomes unusable
- table editing becomes visually confusing
- debug UI leaks back into Normal Mode
- user explicitly asks for visual polish
