# UX regression matrix

| Journey | Expected behavior |
|---|---|
| Open note | Phone-width library does not clip actions. |
| Move canvas | One-finger pan and pinch zoom remain available. |
| Write | S Pen routes to ink without requiring a finger-mode change. |
| Create text | Blank tap creates one visible text box at a readable width. |
| Reopen text | Existing text receives focus instead of spawning another box. |
| Keyboard | Active text remains visible after IME resize. |
| Format text | Done and More stay visible; advanced actions remain reachable. |
| Finish text | Text keeps the same apparent size and blends into the page. |
| Insert image | Image is centered, aspect-correct, screen-sized, and selected. |
| Transform object | Drag moves; lower-right resize keeps upper-left anchored. |
| Mixed selection | Lasso can include ink and canvas objects. |
| Structured content | Table, formula, image, and nested controls remain reachable on narrow screens. |
| Search | Current edits save before full-content search; result opens the matching page. |
