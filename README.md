# NeoNote

NeoNote is an Android-first note-taking app for Samsung Galaxy Tab devices with S Pen input. It starts from Google's `android/cahier` sample and preserves the Jetpack Ink pipeline while adding editable table blocks as a separate document layer.

Current phase: Phase 10 (core roadmap implemented).

This repository now contains implementations and devlog entries from Phase 0 through Phase 10.
