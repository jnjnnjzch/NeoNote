# NeoNote

NeoNote is an Android-first note-taking app for Samsung Galaxy Tab devices with S Pen input. It starts from Google's `android/cahier` sample and preserves the Jetpack Ink pipeline while rebuilding the normal note editor around one unified note surface.

Current status: **Unified Note MVP repair**.

NeoNote is not claiming Phase 10 completion. The previous phase roadmap and release-completion wording are superseded by the Unified Note MVP repair plan until the tablet-tested milestones below pass on real Samsung Galaxy Tab hardware.
