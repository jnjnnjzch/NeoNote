# Table Ink Canvas

Table Ink Canvas is an Android-first note-taking app for Samsung Galaxy Tab devices with S Pen input. It starts from Google's `android/cahier` sample and preserves the Jetpack Ink pipeline while adding editable table blocks as a separate document layer.

Current phase: Phase 0.

Phase 0 is limited to repository setup, GitHub Actions, and architecture documentation. App source code should remain identical to the upstream Cahier base during this phase.
